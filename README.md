# LibreDialer
<br>

LibreDialer is a modern, fast, and reliable replacement for the default Android dialer. It is 100% free and open source, with zero ads and zero trackers.

## Key Features
- **Call Recording**: High-fidelity rootless internal call recording (powered by Shizuku).
- **Material You**: Dynamic colors and modern UI following Material Design 3.
- **Customizable**: Heavily customizable themes, dialpad, and call screens.
- **Privacy First**: No telemetry, no ads, and full transparency.
- **Network Switcher**: Advanced 4G/5G automation and manual switching.
- **Dual SIM Support**: Full multi-SIM management and per-contact binding.

## Installation
LibreDialer is available as an APK in the [Latest Releases](https://github.com/MoHamed-B-M/Pdialer/releases).

## Note on Call Recording
Since this app requires Shizuku for internal audio capture, ensure you have Shizuku installed and configured properly. We recommend using a Shizuku watchdog to prevent the service from stopping unexpectedly.
